# 交互设计 v2

## 1. 右键菜单

### 1.1 用户气泡（右键提示词）

用户气泡中的文本/区域支持右键菜单：

| 选项 | 行为 |
|------|------|
| 删除分支 | 删除当前 turn 的 activeBranch 及其所有图片。若 turn 还有其它分支，自动切换到最近有效分支。若 turn 所有分支都被删完，清除整个 turn。如果该分支被后续轮次引用，则不可删除。 |
| 发送到新对话 | 新建对话，将当前 branch 的提示词 + 参数 + 上传图 + 前轮选中图预填到输入区。 |

### 1.2 图片缩略图（右键结果图）

| 选项 | 行为 |
|------|------|
| 保存到本地 | 弹出系统保存对话框，选择路径后写入文件。 |
| 复制 | 将图片写入系统剪贴板。成功/失败弹 Toast 淡化消失。 |
| 发送到新对话 | 新建对话，仅将此图作为附件引用，提示词和参数为空待填。 |
| 删除 | 同现有逻辑，被后续轮次引用的图片不可删除。 |

### 1.3 灯箱右键

全屏查看图片时，右键图片直接复制（不进菜单，同"复制"逻辑）。

## 2. 状态指示器

对话列表右侧（与删除键同一槽位，绝对定位叠放）显示：

| 状态 | 图标 | 位置 |
|------|------|------|
| 生成中 | 暗黄空心圆（2px 边框） | 与 ✕ 同位置 |
| 生成成功 | 绿底 ✓ | 同位置 |
| 生成失败 | 红底 ✗ | 同位置 |
| 用户 hover | 删除键 ✕ | 覆盖指示器 |

- `sending` 和 `unread` 互斥（生成结束后才设 unread），不会同时出现
- hover 时指示器隐藏（`opacity: 0; pointer-events: none`），删除键显示
- 切换对话后清除 unread dot；sending 指示器由内存缓存保持

## 3. 请求独立 + 对话切换

### 独立请求
每个对话的请求状态独立，互不阻塞：
- `state.conversationStates[convId] = { sending: false }`
- main.js 的 `activeRequests` Map 支持多请求并发
- 侧边栏每个对话的 sending 状态通过独立指示器显示

### 对话切换缓存
切换对话时，当前对话缓存到 `state._convCache[convId]`（保留 loading 等瞬态字段），目标对话优先从缓存读取。避免 loading 状态走磁盘 IO 丢失。

### 停止生成
点击停止后，分支保留（含提示词/参数/上传图），只是无结果图片。用户可点击"重试"继续生成或"改写"修改后重试。

## 4. 参数面板

### 默认显示
参数面板在启动时默认展开，可通过齿轮按钮切换。

### 尺寸模式
- **预设模式**：选择比例 + 分辨率，方向按钮切换横/竖版
- **自定义模式**：手动输入宽高（64-8192，须为 64 的倍数），方向按钮变为 ⤢（互换宽高）

### 尺寸校验指示器
自定义模式下，输入框右侧实时显示：

| 状态 | 图标 | 含义 |
|------|------|------|
| 合法 | 绿 ✓ | 在 64-8192 范围内且为 64 倍数 |
| 超出范围 | 红 ✗ | 超出 64-8192 |
| 非 64 倍数 | 暗黄 ➤ | 在范围内但不是 64 倍数，点击自动修正 |

不合法时发送会弹 Toast 阻止。尺寸范围标识后显示 `64n` 提示。

## 5. n 不记录历史

- 存盘时从 `turn.params` 去掉 `n`
- 加载旧数据时如果 `turn.params` 有 `n`，删除它（视为历史遗留）
- 历史元数据显示中不显示 n
- 重试时 n 由输入框当前值决定（buildApiParams 使用 state.params.n）

## 6. 输入草稿独立

`state.drafts[convId] = { text, uploadedImages, params }`

- 切换对话时保存旧对话草稿、加载新对话草稿
- 仅内存，不持久化
- 每次 input/params/uploadedImages 变化时自动更新草稿
