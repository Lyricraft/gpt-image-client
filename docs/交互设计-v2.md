# 交互设计 v2

## 1. 右键提示词菜单

用户气泡中的文本/区域支持右键菜单：

| 选项 | 行为 |
|------|------|
| 删除 | 删除当前 turn 的 activeBranch 及其所有图片。若 turn 还有其它分支，自动切换到第一个可用分支。若 turn 所有分支都被删完，清除整个 turn。如果该分支包含被选中的图片，则该分支不可删除（菜单项灰显或隐藏）。 |
| 发送到新对话 | 新建一个对话，将：当前 turn 的提示词文案 + 当前 turn 的参数（不含 n）+ 当前 turn 的上传图片 + 前一个 turn 的选中图（如果有）预填到新对话的输入区，等待用户点发送。 |

实现：用户气泡 `.user-bubble` 加 contextmenu 监听，根据条件显示菜单项。

## 2. 请求独立 + 未读气泡

### 独立请求
每个对话的请求状态独立，互不阻塞：
- `state.conversationStates[convId] = { sending: false }`
- 切换对话时：保存当前对话草稿，加载目标对话草稿，根据目标对话的 sending 状态更新按钮
- main.js 的 `activeRequests` Map 已经支持多请求并发

### 未读气泡
`state.unread[convId] = { type: 'success' | 'error', message }`

- 请求完成/失败时，如果用户当前不在该对话，在对话列表右侧显示气泡
- 绿色：请求成功；红色：请求失败
- 用户切换到该对话时，气泡立即消失
- 中止（按停止）不产生气泡

### 渲染
对话列表项 `.conv-item` 内新增 `.unread-dot` 元素：
```html
<span class="unread-dot success">✓</span>
<span class="unread-dot error">✗</span>
```

## 3. n 不记录历史

- 存盘时从 `turn.params` 去掉 `n`
- 加载旧数据时如果 `turn.params` 有 `n`，删除它（视为历史遗留）
- 历史元数据显示中不显示 n
- 重试时 n 由输入框当前值决定（buildApiParams 使用 state.params.n）

## 4. 输入草稿独立

`state.drafts[convId] = { text, uploadedImages, params }`

- 切换对话时保存旧对话草稿、加载新对话草稿
- 仅内存，不持久化
- 每次 input/params/uploadedImages 变化时自动更新草稿

## 5. 文件改动

| 文件 | 改动 |
|------|------|
| `renderer.js` | 右键提示词菜单、请求独立状态、未读气泡、草稿独立、n 剥离 |
| `styles.css` | 未读气泡样式 |
| `main.js` | 无改动（activeRequests 已支持并发） |
